# 데이터 수집 시제품 (pipeline)

미국·한국 경제 지표를 원천 기관에서 직접 받아 월별로 맞추고, 지표 간 상관계수를 계산해 앱이 받을 파일을 만든다.
Python 표준 라이브러리만 사용하므로 GitHub Actions에서 따로 설치할 것이 없다.

## 실행

```bash
python3 pipeline/build.py
```

```bash
ECOS_API_KEY=발급받은키 python3 pipeline/build.py
```

- 원본 다운로드는 `pipeline/.cache/`에 20시간 보관한다 (반복 실행 시 원천 서버에 부담을 주지 않음).
- 수집 실패가 하나라도 있으면 종료 코드 1을 반환한다 → GitHub Actions에서 실패 알림으로 쓸 수 있다.
- 한국은행 데이터는 `ECOS_API_KEY`가 있을 때만 받는다. 인증키는 [ECOS](https://ecos.bok.or.kr)에서 무료로 발급한다. 키는 파일에 저장하지 말고 GitHub Actions 비밀값으로 넣는다.
- BLS는 키 없이 하루 25회까지 요청할 수 있고, 한 번 실행하면 6회를 쓴다. `BLS_API_KEY`가 있으면 v2 API를 쓴다.

## 자동 실행 (GitHub Actions)

| 워크플로 | 실행 | 하는 일 |
|---|---|---|
| `weekly-data.yml` | 매주 월요일 03:00 KST (+ 수동 실행) | `build.py` 실행 → 성공하면 `out/`을 커밋. 실패하면 커밋하지 않아 이전 데이터가 그대로 유지되고, GitHub이 소유자에게 메일로 알린다 |
| `monthly-fed-archive.yml` | 매월 2일 (+ 수동 실행), 2027-03-31까지 | `archive_fed.py` 실행 → 연준 릴리스 전체를 GitHub Release 첨부 파일로 보관 (git 기록 밖이라 저장소가 커지지 않음) |

필요한 저장소 비밀값 (Settings → Secrets and variables → Actions):
- `ECOS_API_KEY` (필수): 한국은행 ECOS 인증키
- `BLS_API_KEY` (권장): BLS 무료 키. GitHub 실행기는 IP를 여러 사용자가 함께 쓰므로, 키 없이 쓰는 하루 25회 한도가 다른 사용자 때문에 먼저 찰 수 있다

앱은 `out/manifest.json`을 먼저 받아, 해시가 바뀐 파일만 다시 받는다.

## 결과 파일 (`pipeline/out/`)

| 파일 | 내용 | 크기 (미국, 32개 지표) |
|---|---|---|
| `us/series.json` | 지표별 월별 값 (1970년~) | 103KB → gzip 40KB |
| `us/edges.json` | 모든 지표 쌍의 60개월 롤링 순위 상관계수(3개월 변화), 매월 하나씩 (타임머신용) | 748KB → gzip 118KB |
| `report.md` | 기대 관계 검증, 강한 관계 후보, 데이터 범위 | — |

→ 앱이 처음 받는 데이터는 약 200KB다. 무료 호스팅 한도에 비하면 매우 작다.

## 첫 실행 결과 요약 (2026-11-22, 미국)

수집: 연준(H.15, H.10, H.6, G.17, H.4.1, EBP), BLS, World Bank Pink Sheet, Kraken → **32개 지표 모두 성공** (2026-10월까지)

기대 관계 27쌍: **✅ 18 · 🟡 2 · ⚪ 7 · ❌ 0**

### 잘 맞는 관계 (설명 그대로 사용 가능)
- 달러 ↔ 금 −0.52, 실질금리 ↔ 금 −0.44, 달러 ↔ 유가 −0.65
- 물가 ↔ 유가 +0.71, 기대인플레이션 ↔ 유가 +0.67, PPI ↔ CPI +0.91
- 기준금리 ↔ 2년물 +0.82, BTC ↔ ETH +0.89
- 기간 대부분에서 부호가 유지된다 (부호 유지율 84~100%).

### 상관계수로 잘 안 보이는 관계 (⚪ 7개) → 기획 반영 필요
1. **지연이 길거나 수준에 따른 관계**: 장단기 금리차 역전 → 1~2년 뒤 실업 증가, 금리 인상 → 실업 증가. 변화량끼리의 상관으로는 거의 0으로 나온다.
   → 앱에서 상관선 대신 **"선행 신호(Leading signal)" 설명 카드**로 따로 보여 준다. 예: 금리차가 역전된 기간을 차트에 음영으로 표시.
2. **기준금리 ↔ 달러**: 달러는 미국 금리 자체가 아니라 **다른 나라와의 금리차**에 반응한다. → 이론 설명을 고쳐 쓴다. 한국 화면에서는 "한미 금리차 ↔ 원/달러"로 보여 준다.
3. **연준 자산 ↔ 비트코인, 실질금리**: 시기에 따라 부호가 바뀐다 (부호 유지율 38~50%). → "Usually + / now −" 배지를 보여 줄 대표 사례로 쓴다.
4. **물가 ↔ 임금, 구인 ↔ 임금**: 2020년 코로나 때 저임금 일자리가 먼저 사라져 평균 임금이 급등한 왜곡이 섞여 있다.

### 극단값 문제 (2020년 코로나)
- 실업률 ↔ 고용 증감은 일반 상관 −0.94, 순위 상관 −0.75다. 산업생산 ↔ 실업률은 −0.74와 −0.52다. 2020년 몇 달이 숫자를 부풀린다.
- → **앱의 상관 계산에는 순위 상관(Spearman)을 쓰거나 극단값을 잘라 내는 것을 권장**한다. 한 번의 사건이 관계선 전체를 지배하지 않게 하기 위해서다.

### 관계선 계산 기준 → 확정: 3개월 변화 · 60개월 창 · 순위 상관 · |r| ≥ 0.4

`experiment_edges.py`로 5개 기준 × 2개 방법을 미국·한국 데이터로 비교했다 (`out/experiment_edges.md`, `out/exp_show_0.4.md`).

| 기준 (순위 상관, 표시 0.4) | 확실한 관계의 부호 일치 | 선 표시 | 잘못된 선 | 월간 흔들림 | 타임머신 시작 |
|---|---|---|---|---|---|
| 1m 변화 · 36m 창 | 92% | 60% | 4% | 0.032 | 1993 |
| **3m 변화 · 60m 창 (채택)** | **97%** | **73%** | **5%** | **0.019** | **1995** |
| 12m 변화 · 120m 창 | 100% | 93% | 11% | 0.009 | 2000 |

(미국 기준. 한국: 채택안 부호 일치 100%, 선 표시 80%, 잘못된 선 6%)

- 1m·36m: 잘못된 선은 적지만, 확실한 관계도 40%의 시점에서 선이 사라진다.
- 12m·120m: 가장 부드럽지만 잘못된 선이 2배다. 10년 창이라 관계 변화에 늦게 반응하고 타임머신이 2000년부터 시작한다.
- 표시 기준 0.3에서는 잘못된 선이 15%라서 **0.4로 올림**. 이렇게 해도 확실한 관계는 대부분 보인다.
- 비교 화면 설명 문장은 전체 기간 12개월 변화 기준을 쓴다 (경기 흐름에 가까움).
- 확정한 기준은 `build.py`의 `EDGE_H`, `WINDOW`, `EDGE_METHOD`, `SHOW_TIERS`에 적용했다. `edges.json`에도 같은 값이 기록된다.

## 한국 결과 (2026-11-22, ECOS 수집 성공)

수집: ECOS 5개(기준금리, 국고채 3년·10년, CPI, 실업률) + 연준 원/달러 + 글로벌 공통 7개 → 15개 지표
파일 크기: series 39KB, edges 147KB (gzip 약 28KB)

기대 관계 8쌍: **✅ 3 · 🟡 2 · ⚪ 2 · ❌ 1**

### 잘 맞는 관계
- 달러지수 ↔ 원/달러 +0.67 (부호 유지율 100%)
- 국고채 10년 ↔ 미국 10년 +0.63 (100%): 한국 장기금리는 미국을 따라간다
- 기준금리 ↔ 국고채 3년 +0.53

### 반대로 나온 관계 (❌): 한미 금리차 ↔ 원/달러
- 이론: 한국 금리가 미국보다 높아질수록 원화가 강해진다 (원/달러 하락, −).
- 실제: +0.29. 금리차의 변화는 주로 **미국 금리 변화**에서 나온다 (금리차 ↔ 미국 기준금리 −0.82). 미국이 금리를 크게 내린 시기는 2001년, 2008년, 2020년 같은 위기 때였다. 그때 금리차는 한국 쪽으로 벌어졌지만, 위험 회피로 원화는 오히려 약해졌다.
- → 앱 설명: "In theory a wider KR–US gap supports the won, but in crises the Fed cuts while the won weakens — risk sentiment dominates." 이론과 실제가 다른 대표 사례로 쓴다.

### 새로 발견한 한국 특화 관계 (설명 추가 후보)
- **원/달러 ↔ 비트코인 −0.63, 이더리움 −0.63**: 원화는 위험 선호 통화처럼 움직인다. 위험자산이 오를 때 원화도 강해진다. 한국 사용자에게 흥미로운 포인트다.
- 기준금리 ↔ 장단기 금리차(10Y−3Y) −0.71: 금리를 올리면 금리차가 좁아진다
- 국고채 3년 ↔ CPI +0.54, 기준금리 ↔ 유가 +0.46

### 약한 관계 (⚪·🟡)
- 물가 → 기준금리 (6개월 지연) +0.14, 장단기 금리차 → 실업률: 미국과 같은 이유로 상관계수로는 잘 안 보인다. 선행 신호 카드로 처리한다.
- 유가 → 한국 CPI +0.17: 미국(+0.71)보다 훨씬 약하다. 한국은 원/달러 환율과 정부의 유류세·공공요금 조정이 함께 작용하기 때문으로 추정한다 (검증 필요).

### 데이터 시작 시점
- 기준금리 1999-05부터 (현행 기준금리 체계 이전 자료 없음), 국고채 10년 2000-10, 실업률(계절조정) 1999-06
- → 한국 관계선은 대부분 2000년대 이후만 계산 가능하다. 타임머신에서 그 이전 시점은 "데이터 없음"으로 표시해야 한다.
